# tegaki-template-generator

手書き文字（ひらがな・カタカナ・常用漢字・記号など）をまとめて収集するための、
印刷用グリッド原稿を自動生成するツールです。ブラウザ内で完結し、外部送信は一切ありません。

`tegaki-template-generator.html` をブラウザで開くだけで使えます（インストール不要）。

---

## できること

- ひらがな / カタカナ（濁点・半濁点・拗音・促音込み）/ 数字 / 英字 / 記号 / **常用漢字2136字** を
  チェックボックスで選んでグリッド原稿を自動生成
- 好きな文字をテキストエリアに追加して収録対象に含める
- 列数・行数・余白（mm）を指定 → セルサイズは自動計算してA4に敷き詰め
- 四隅に**トンボ（位置合わせマーク）**を印字 → スキャン後の傾き補正の基準にできる
- 各マスに**通し番号**を表示 → 「何番目のマス＝リストの何文字目」が機械的に確定する
- ガイド文字の色・太さを調整可能（薄いグレー推奨。後工程の2値化で消しやすい）

## 使い方

1. `tegaki-template-generator.html` をブラウザで開く
2. 左側パネルで収録したい文字セットにチェック
3. 列数・行数・余白を決めて「この設定でテンプレート生成」
4. 「印刷 / PDFとして保存」でブラウザの印刷機能からPDF化 → 印刷して手書きしてもらう
5. 「文字順序をJSONで書き出す」で `tegaki-char-order.json` を保存しておく
   （この原稿と同じ並び順の文字リストなので、後で検出結果と自動で対応付けるときに使う）

## JSON出力の形式

```json
{
  "characters": ["あ", "い", "う", "...", "鬱"],
  "count": 2300
}
```

`characters` の配列インデックス（0始まり）が、原稿のマス番号（1始まり）に対応します。
マス番号 `n` の文字は `characters[n - 1]` です。

## 想定している後工程（次のステップ）

1. 印刷した原稿に手書き → スキャン/撮影
2. 四隅のトンボを基準に画像の傾き補正
3. グリッド座標から各マスの黒い部分を切り出し
4. マス番号と `tegaki-char-order.json` を突き合わせて、**目視マッピングなしで文字を自動割り当て**
5. 切り出した画像を SVG パス化（imagetracerjs / potrace 等）

## 注意点

- 常用漢字リストは常用漢字表（平成22年内閣告示第2号）に準拠していますが、簡易的な収録です。
  実運用前に文字の過不足がないか一度確認してください。
- 全部の文字セットを有効にすると2000字を超えるため、印刷ページ数もそれなりになります
  （初期設定10列×12行=120マス/ページで、全部乗せだと約19〜20ページ）。
